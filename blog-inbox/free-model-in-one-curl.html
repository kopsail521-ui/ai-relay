The whole path in three steps

Every new KeyoAPI account starts with a $10 gift credit. Free catalog IDs (the ones ending in :free) bill against that credit at fair-use limits, so you can prototype before you ever top up.

  1. Create an account and mint an API key in the console.
  2. Point your client at https://www.keyoapi.xyz/v1.
  3. Call any :free model ID — for example gemma-4-26b:free.

One curl

curl https://www.keyoapi.xyz/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemma-4-26b:free","messages":[{"role":"user","content":"hi"}]}'

The full list of fixed-$0 IDs lives on /free-models; fair-use rate limits apply per model. When you outgrow them, switch model= to a metered ID on the same key — no other change is needed.
