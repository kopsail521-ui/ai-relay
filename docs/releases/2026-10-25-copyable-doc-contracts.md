# 2026-10-25 接入文档与实际调用合同复核

本轮目标：找出用户原样复制文档、模型页请求或终端示例仍会失败的原因。使用公开 GET、生产只读渠道类型查询、源码审查、临时 SQLite 钱包和本机假处理服务；没有调用真实模型、生成音视频或图片，没有产生模型费用。

## 确认的问题与处理

| 问题 | 对用户的影响 | 处理 |
| --- | --- | --- |
| 图片目录已下架 `gpt-image-2.5` 基础款和两个 2.5 VIP，但文档仍推荐 | 复制型号后无可用渠道 | 推荐表、复制按钮、七语言说明统一为当前七个已文档化图片型号；不删除历史任务兼容 |
| Seedance 的四个 480p SKU 进入 H3 专用 builder | 改发其他模型，20 秒被裁到 15 秒，参考音视频丢失 | 使用对应视频协议 builder，保留目录型号、时长、参考素材角色、画幅和种子 |
| H3 参考图请求漏传参考音频、画幅和种子 | 示例校验通过，实际请求与用户意图不符 | 使用协议规定的 `extra` 字段，区分首帧与参考图；超量或互斥参数前置拒绝 |
| H3 无图示例写 480p，实际路线仅 768p/2k、整数 4–15 秒 | 分辨率被静默替换，部分请求在处理端拒绝 | 文档和模型页复制请求改为 768p；不支持的参数在扣费前明确报错；VIP 默认也使用有效档位 |
| H3 无图任务查询使用通用视频路径 | 正确提交后，照文档轮询也拿不到结果 | 按持久化的提交路线使用正确查询协议，保留公开统一查询路径与任务归属检查 |
| H3 提交收到 5xx 或 2xx 无任务号时继续换候选 | 结果未知时可能产生重复任务 | 只在明确模型拒绝时换候选；未知结果不自动重提，错误文案要求联系支持 |
| 专属媒体网关继续透传 `Expect` / `Transfer-Encoding` / hop headers | 正确 multipart 上传在到达处理端前就失败 | 清除原连接握手与分帧头，保留正文、Content-Type、鉴权和幂等信息，不添加生成重试 |
| 单数 `/v1/task/{id}` 查询的网络异常没有捕获 | 一次断连可使整个专属网关进程退出 | 查询设置有限超时；返回 `502 task_query_unavailable`、原任务 ID 和 Retry-After；后续继续查询同一任务 |
| Gemini TTS 广告 `/v1/audio/speech`，实际渠道仅支持 Gemini 原生协议 | Go 音频适配器返回 not implemented | 文档与模型页改为原生 generateContent；说明 JSON/base64 音频解析，不把 JSON 当 WAV |
| Bash 多行 cURL 示例直接粘贴到 Windows PowerShell | URL 单独执行，鉴权和 JSON 参数拆成无效命令 | 明确标注 Bash；添加 PowerShell 5.1/7 专用示例并验证 UTF-8 请求与响应 |
| 一页纸的 Grok 视频路径前后矛盾 | AI 工具可能选择无路由的原生视频入口 | 统一为当前 Chat Completions 合同，去除过时自动转发承诺 |
| 字幕擦除、视频增强文档先于完整公开接入实现 | 复制示例进入错误服务；现有备用实现缺少完整鉴权、计费和任务持久化 | 撤下可执行示例，模型页标记待确认，文档明确暂不可用；没有开放不完整实现 |
| Agnes 出现在已文档化清单，但没有完整字段合同 | AI 工具容易猜测请求 | 移入待确认清单，不宣称已验证不可用 |
| FAQ 正文误嵌多个 H1、金额文字损坏 | 新用户指引不可信 | 重写开场指引，保留可核实内容 |

## 验证方法

- 从中英文手册、一页纸及七语言页面提取实际 JSON，调用生产使用的 validator 与 builder；模型页复制请求也纳入回归。
- 使用真实本机 HTTP 服务验证大文件 Expect/chunked 请求的正文 SHA256 一致、处理端收到一次；轮询断连及超时后进程仍存活，继续 GET 可以取回结果。
- 使用临时钱包和任务数据库验证 H3 查询路径、跨账号拒绝、错误查询不跨路线回退，以及提交结果未知时不尝试其他候选。
- 从实际文档提取九份 PowerShell 示例，分别在 5.1 和 7 运行，共十八次本机请求，验证鉴权、中文 JSON 和响应读取；公网模型请求为零。
- 部署回归覆盖构建先于停止、保留容器配置与持久挂载、共享钱包身份、监听 PID、源码哈希、失败恢复；旧的配置重置式部署仅允许显式手动触发。

生产只读诊断 `40194525133` 确认 Gemini 两个 TTS 型号的现有启用渠道为 type 24；没有读取渠道密钥、用户数据或调用记录。Go 的 Gemini `ConvertAudioRequest` 尚未实现，因此不能继续推荐 OpenAI speech 示例。

## 发布与限制

源码、文档和回归检查分别发布后，验证自动化结果、运行进程源码哈希与公开文档内容；具体完成证据在最终发布记录补充。

本轮没有执行真实生成，因此不能证明处理端实时容量、生成质量或任意素材都能成功。字幕擦除、视频增强仍属于尚未开放的能力，并未通过修改文案变为可用。任务状态未知时不能盲目重提；图片专属幂等机制也不能推导为所有音视频接口都支持幂等。
