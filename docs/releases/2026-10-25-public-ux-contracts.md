- 修正 SDK/REST 主机、鉴权、JSON 示例及 ZCode/Cursor 配置指引，说明连通性探针的实际边界。
- 计价单位区分字符、页、秒、请求和 token；规格价格表保留，删除简介中的过期固定费率。不修改真实计费配置。

- 定价请求超时/失败显示可恢复错误；登录初始化显示加载状态，限制跨标签页锁等待；语言资源按需加载，窄屏登录布局可滚动。
- 邮件恢复入口根据实际邮件配置显示可用性；用户名注册说明邮箱恢复前提。不会把未验证邮箱当成已绑定邮箱。
- 发布前运行离线校验；控制台镜像固定提交 SHA；代理部署失败恢复旧容器，保留未纳管博客且让 Git 修正文优先。
- 修正真实发版误判：旧的回滚容器占用 3001，新容器在重启，原有 HTTP 200 检查误认成功。现要求进程非重启、正 PID 实际持有端口、容器四个源文件 SHA 与 checkout 相同，并由相同 PID 连续通过两轮。外来端口占用会在停服务前中止，运行中的备份不会被清理。
- 代理自动发布末尾增加四个公网 GET 验收，检查整个模型目录的能力、请求格式及轮询路径，以及登录页和定价页的实际版本。全程没有生成或聊天请求。
- 目录端点筛选与计数共用语义映射，能够识别模型精确的创建路径；新增实际存在的语音、OCR、数字人等类型，没有对应协议的零项不再误导展示。计费 token 单位移到聊天价格旁，音视频卡片不再显示裸「1M」标签；详情仅展示聊天合同中实际提供的有限正数上下文信息。
