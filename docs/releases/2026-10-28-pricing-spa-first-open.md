# 首次进入模型页不显示分组价格（2026-10-28）

用户截图显示同一型号的价格卡首次打开只有手册链接，刷新后才出现分组价格表。已确认一条可复现路径：以登录/注册页面启动 SPA，再通过客户端导航进入 `/pricing`，打开模型详情。

## 原因与修复

代理为减轻登录页负担，不在认证页面注入完整模型数据和价格表脚本。客户端导航不会重新请求 HTML，导致从认证页面进入定价页的会话缺少该脚本。直接刷新 `/pricing` 会收到完整脚本，所以又能显示。这是网站加载逻辑缺陷，不能归因于用户电脑。

认证页现在只携带约 1KB 的延迟加载器；访问 `/pricing` 或 `/models` 时才通过同源 GET `/api/marketplace/pricing-ui.js` 加载现有公开文案数据与价格表逻辑。价格表脚本只下载一次，历史导航和重复打开复用已加载内容，失败后可以通过重连、点击或再次导航重试。登录页不下载完整目录、不启动价格表扫描，浏览器历史状态、参数与返回值保持不变。

未修改模型价格、扣费规则、余额、认证逻辑或模型调用参数。

## 验证

- 修改前新增回归稳定失败：认证页面没有加载器，无法在同一会话内加载分组价格。
- 修改后本机代理回归通过：认证页轻量、首次导航下载脚本、重复导航不重复下载、失败重试、返回历史页面、JavaScript MIME/nosniff 与 HEAD 行为。
- 本机 JSDOM 使用真实代理 HTML 与 JavaScript、真实 DOM 与 MutationObserver，所有 HTTP 均限制本机回环。由 `/sign-in` 导航至 `/pricing`，零刷新情况下连续打开 Claude Opus 5.5（三档）、Duix-Avatar（四档）、gpt-image-2（五档），表格及全部价格单元格与公开数据一致，只请求一次价格脚本。结果：`tmp/pricing-spa-dom-result.json`。

- 发布后公共 GET 验收已补充认证页加载器及定价脚本入口，避免只检查硬刷新 `/pricing` 而漏掉本次问题。
