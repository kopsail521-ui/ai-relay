# UnoRouter price guard

UnoRouter's public platform API exposes the current catalog at `https://api.unorouter.com/api/pricing/catalog`. The `input_price` and `output_price` fields are the current dollars-per-million-token prices selected by its default provider routing. The existing Keyo configuration is a static snapshot, so it cannot protect a fixed sell price when upstream costs move.

This repository now includes `scripts/unorouter-price-guard.py`. It reads that catalog every five minutes through the supplied systemd timer and disables only the matching channel's `abilities.enabled` row when the live input or output cost reaches policy. Other channels for the same model remain eligible. It does not change user balances, public model prices, provider keys, or request bodies.

The example policy uses a default maximum upstream cost of 80% of Keyo's configured sell price, leaving 20% gross margin before payment and infrastructure costs. Per-model absolute caps can override that ratio. The active production policy is configured separately at **50% of sell price**, as selected by the operator, for all 14 paid UnoRouter models. The guard fails closed after 15 minutes without a successful catalog read, requires two consecutive within-policy reads to recover, and writes only sanitized state (model names, prices, reasons and timestamps) to the state file.

The checked-in `config/unorouter-price-guard.json` contains the active 50% policy for the 14 paid models on `Keyo Chat`. It also guards the two gift-credit models on `Keyo Chat Free` using their upstream IDs and absolute caps: `glm-5.2` must stay below `$0.01/M` input and `$0.08/M` output for public `glm-5.3:free`; `deepseek-v4.1-flash-1017` must stay below `$0.01/M` input and `$0.07/M` output for public `deepseek-v4.1-flash-1017:free`. The guarded deployment workflow installs the systemd service and five-minute timer after the normal safe-pull. A blocked model remains visible in the catalog but calls receive the platform's normal no-available-channel response; the request is stopped before UnoRouter is called. The example remains disabled for copying into another environment. Run the script with `--dry-run` before changing a policy.

The live price source and field meanings are documented by [UnoRouter's Platform API](https://unorouter.com/en/docs/platform/platform-api). If a channel is pinned to a specific provider group, use the per-model endpoint and group prices instead of the catalog summary.
