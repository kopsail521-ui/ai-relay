## 打印部署命令

在仓库根目录执行以下命令只打印脚本，不连接 VPS 或执行部署：

```bash
node scripts/print-vps-image-fixes.mjs --stdout
```

默认包含 native 与审核代理两个服务的运行源码和部署 helper。单服务打印选项为 `--native-only --stdout` 或 `--moderation-only --stdout`。不带 `--stdout` 会将命令写到 `scripts/vps-image-fixes.txt`；生成器不读取 `.env` 或凭据。输出须审查后由获授权的运维人员执行。

## VPS 动作与顺序

目标是已有配置的 Linux Docker 安装，仓库路径 `/opt/ai-relay`。helper 不提供首次安装或创建密钥的流程。

```bash
sudo python3 /opt/ai-relay/scripts/vps-deploy-images.py diagnostics
sudo python3 /opt/ai-relay/scripts/vps-deploy-images.py deploy
```

`diagnostics`（别名 `diagnose`）只读检查。`deploy`（别名 `all`）按 native → moderation 更新两服务。`native` 和 `moderation` 只更新指定服务；单服务分步部署同样应先 native 再 moderation。`rollback` 恢复保留的旧容器。

helper 从现有容器 inspect 配置生成新容器，保留环境、网络、端口、用户、命令和挂载；先构建再停止旧容器，健康检查失败会尝试恢复。成功后旧容器保留用于回滚。脚本失败时应停止后续操作；不要自行清理陌生或回滚容器。

## 持久化与计费前提

native 图片任务账本写入现有 New API SQLite 钱包。必须共享真实钱包文件所在的可写持久目录，覆盖 SQLite WAL/SHM；交付 ACK 目录也须可写且持久保存，不能使用 tmpfs 或仅挂载数据库单个文件。

helper 对不兼容的钱包配置拒绝部署，包括远程数据库、不同钱包文件、独立日志库及未同步的 Redis/batch 余额配置。拒绝时应评估具体配置；本次未授权自动改变这些生产设置。

审核代理上传目录必须可写且持久挂载。VPS 上还须核对上传目录的宿主机来源与 Caddy `/uploads` 静态目录一致，并检查权限、空间和真实上传/读回。离线测试不能确定此前上传 503 的生产原因。
