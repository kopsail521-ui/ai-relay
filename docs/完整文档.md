## 一、产品是什么（一句话）

你开了一家 **AI 模型代购店**：

- 客户只用 **一个地址 + 一把钥匙（API Key）**
- 背后货从 **Grsai** 进
- 你统一计费、发令牌、加价出售

客户不需要注册 Grsai，也不需要懂国内站。

```
客户 / Cursor / 自己的程序
        ↓  BASE/v1  +  sk-你发的令牌
     你的 New API（中转站）
        ↓
     Grsai（上游供货）
```

## 二、给客户用

### 2.1 你需要发给客户的三样东西

| 项目 | 示例 | 说明 |
|------|------|------|
| **接口地址（Base URL）** | `https://api.你的域名.com/v1` | 本机测试用 `http://127.0.0.1:3000/v1` |
| **API Key** | `sk-xxxxxxxx` | 在你后台「API 密钥」里生成，一人一把 |
| **模型名** | 见下表 | 必须写对，写错会报模型不存在 |

### 2.2 模型列表

#### 文本（聊天 / 编程）

| 模型名 | 说明 | 计费 |
|--------|------|------|
| `gpt-5.6-terra` | 日常对话与编程，更便宜，推荐默认 | 按输入/输出 token |
| `gpt-5.6-sol` | 高质量档，适合复杂写作、推理 | 按输入/输出 token |

接口：`POST {BASE}/v1/chat/completions`

#### 图片

| 模型名 | 说明 | 计费 |
|--------|------|------|
| `gpt-image-2` | 文生图/图生图，约 1K | 按张 |
| `gpt-image-2-vip` | 高清，支持 1K/2K/4K | 按张 |
| `nano-banana-2` | 新一代出图，速度快 | 按张 |
| `nano-banana-pro` | 高质量出图，多比例/分辨率 | 按张 |

接口：`POST {BASE}/v1/images/generations`

### 2.3 参考售价（约）

汇率按站点约 **1 USD ≈ 7.3 CNY**。以下为当前后台配置对应的售价（可改）。

**文本（人民币 / 百万 tokens）**

| 模型 | 输入 | 输出 |
|------|------|------|
| `gpt-5.6-terra` | ≈ ¥4.05 | ≈ ¥23.4 |
| `gpt-5.6-sol` | ≈ ¥9.9 | ≈ ¥58.5 |

**图片（人民币 / 张）**

| 模型 | 约价 |
|------|------|
| `gpt-image-2` | ≈ ¥0.14 |
| `nano-banana-2` | ≈ ¥0.24 |
| `nano-banana-pro` | ≈ ¥0.41 |
| `gpt-image-2-vip` | ≈ ¥0.45 |

> 上游进货价常有区间；对外请卖**固定标价**。改价在 New API「系统设置 → 模型相关」。

### 2.4 在 Cursor 里怎么用

1. 打开 Cursor 设置里的 Models / API  
2. 打开「Override OpenAI Base URL」之类选项  
3. 填入：
   - **Base URL**：`http://127.0.0.1:3000/v1`（或你的公网 `/v1`）  
   - **API Key**：你发给自己的 `sk-...`  
   - **Model**：`gpt-5.6-terra`  
4. 保存后新开对话试一句

其他兼容 OpenAI 的工具（Cherry Studio、ChatBox、自建脚本）同理：**改 Base URL + Key + 模型名**。

### 2.5 接口示例

#### 聊天

```bash
curl https://你的域名/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"gpt-5.6-terra\",
    \"stream\": false,
    \"messages\": [{\"role\": \"user\", \"content\": \"你好\"}]
  }"
```

流式：把 `"stream": true`，按 SSE 接收。

#### 画图

```bash
curl https://你的域名/v1/images/generations \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"nano-banana-2\",
    \"prompt\": \"一只边牧在草地上\",
    \"size\": \"1024x1024\",
    \"response_format\": \"url\"
  }"
```

成功时 `data[0].url` 为图片链接。

#### 查看可用模型

```bash
curl https://你的域名/v1/models \
  -H "Authorization: Bearer sk-你的令牌"
```

### 2.6 常见报错（客户向）

| 现象 | 可能原因 | 怎么办 |
|------|----------|--------|
| 401 / 鉴权失败 | Key 错了或被禁用 | 找你重新发令牌 |
| 模型不存在 | 模型名拼错 | 对照上表 |
| 余额不足 | 额度用完 | 找你充值 |
| 超时 / 502 | 上游或你的站挂了 | 稍后重试或联系你 |
| 连接失败 | 地址错或你没上线 | 确认 Base URL 能否浏览器打开 |

## 三、给你自己用（运维）

### 3.1 目录结构

```
ai-relay/
  bin/new-api.exe              # Windows 网关程序
  new-api/                     # New API 源码（备查）
  pricing-admin/               # 成本/售价/官方价对照后台（账本）
  config/grsai.json            # Grsai 模型清单
  scripts/
    setup-grsai-channel.mjs    # 自动创建 Grsai 渠道
    setup-model-meta-pricing.mjs  # 介绍/图标/售价
    test-grsai.mjs             # 直连上游测试
  docs/                        # 本文档
  data/                        # 运行数据（勿提交密钥）
  .env                         # 本地密钥（勿提交 git）
  start-new-api.bat
  start-pricing.bat
  docker-compose.yml
```

### 3.2 本机启动

**网关（必须）**

```bat
start-new-api.bat
```

打开：http://localhost:3000  

**价格账本（可选）**

```bat
start-pricing.bat
```

打开：http://localhost:3100 ，默认密码见 `.env` 的 `ADMIN_PASSWORD`

两套东西别混：

| | New API | 价格后台 |
|--|---------|----------|
| 作用 | 真转发、真扣费 | 给你看成本/售价/官方价 |
| 客户用不用 | 用 | 不用 |

### 3.3 `.env` 要填的

从 `.env.example` 复制为 `.env`：

```env
GRSAI_BASE_URL=https://grsaiapi.com
GRSAI_API_KEY=你的Grsai密钥

NEW_API_BASE=http://127.0.0.1:3000
NEW_API_ADMIN_USER=你的管理员用户名
NEW_API_ADMIN_PASSWORD=你的管理员密码

ADMIN_PASSWORD=价格后台密码
PORT=3100
```

### 3.4 进货渠道（Grsai）

首次或重建渠道：

```bat
node scripts/setup-grsai-channel.mjs
```

成功后，后台「渠道」里应有 **Grsai 上游**，模型串包含：

`gpt-5.6-sol,gpt-5.6-terra,gpt-image-2,gpt-image-2-vip,nano-banana-pro,nano-banana-2`

直连测上游（不经过你的站）：

```bat
node scripts/test-grsai.mjs
```

### 3.5 模型介绍 / 图标 / 售价一键写入

```bat
node scripts/setup-model-meta-pricing.mjs
```

脚本里改 `sellInCny` / `sellOutCny` / `sellPerCallCny` 后再跑，即可更新对外扣费。

**定价规则（New API）**

- 文本：`模型倍率` ≈ 输入美元价(每百万) ÷ 2；`补全倍率` = 输出价 ÷ 输入价  
- 图片：`模型固定价格` = 美元/张  
- 汇率默认约 7.3  

也可在网页：**系统设置 → 模型相关 / 分组与模型定价** 手动改。

### 3.6 给客户发令牌

1. 登录 New API  
2. 左边 **「API 密钥」** → **新建**  
3. 复制 `sk-...` 发给客户（不要把 Grsai 的进货 Key 给客户）  
4. 可随时禁用某一把钥匙  

### 3.7 本机自测命令

把 `sk-xxx` 换成你的令牌：

```bat
curl http://127.0.0.1:3000/v1/chat/completions ^
  -H "Authorization: Bearer sk-xxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"gpt-5.6-terra\",\"stream\":false,\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}"
```

画图：

```bat
curl http://127.0.0.1:3000/v1/images/generations ^
  -H "Authorization: Bearer sk-xxx" ^
  -H "Content-Type: application/json" ^
  -d "{\"model\":\"nano-banana-2\",\"prompt\":\"a red circle\",\"size\":\"1024x1024\",\"response_format\":\"url\"}"
```

### 3.8 权重 / 优先级是啥

现在只有一家上游，**可以不管**。

以后多家上游时：

- **优先级**：数字更大的先用  
- **权重**：同一优先级时按比例分流  

### 3.9 安全注意

- `.env`、令牌、Grsai Key **不要提交 git、不要发群聊**  
- 泄露过的 Key **立刻作废重开**  
- 上线后建议：**关闭公开注册**，只发令牌给客户  
- 生产环境设置 `SESSION_SECRET` / `CRYPTO_SECRET`（见 New API 文档）

## 四、上线还差什么

| 状态 | 内容 |
|------|------|
| ✅ 已完成 | 本机网关、Grsai 渠道、6 模型、介绍/图标、售价、本机测通 |
| ❌ 未完成 | 公网服务器（海外 VPS） |
| ❌ 未完成 | 域名 + HTTPS |
| ❌ 未完成 | 客户充值（Stripe / 支付宝等） |
| ❌ 未完成 | 公网上再测一遍聊天+画图 |
| 建议 | 换泄露密钥、关公开注册、备份 `data/` |

上线最小路径：

1. 买海外 VPS → 用 `docker compose up -d` 或拷贝二进制部署  
2. 解析域名到 VPS，配 HTTPS（Caddy / Nginx）  
3. 改 New API「服务器地址」为公网 URL  
4. 接通充值或先人工转账加额度  
5. 把本文 **第二节** 发给客户（把 BASE 换成公网）
