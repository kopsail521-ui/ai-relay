## 6. 语音合成（TTS）

### 6.1 同步（立刻返回音频）

`POST https://www.keyoapi.xyz/v1/audio/speech`

```bash
curl https://www.keyoapi.xyz/v1/audio/speech \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"GLM-TTS\",
    \"input\": \"你好，我是 KeyoAPI。\",
    \"voice\": \"alloy\"
  }" \
  --output speech.wav
```

适合：`GLM-TTS`、`Step-Audio-TTS-3B`、部分 `IndexTTS-2` 场景。

### 6.2 异步（先拿任务 ID，再轮询结果）

`POST https://www.keyoapi.xyz/v1/async/audio/speech`  
然后：`GET https://www.keyoapi.xyz/v1/task/{任务ID}`

```bash
# 创建任务
curl https://www.keyoapi.xyz/v1/async/audio/speech \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d "{\"model\":\"Qwen3-TTS\",\"input\":\"你好，异步语音合成。\"}"

# 用返回的 task id 查结果
curl https://www.keyoapi.xyz/v1/task/任务ID \
  -H "Authorization: Bearer sk-你的密钥"
```

适合：`Qwen3-TTS`、`CosyVoice3`，以及需要异步的 `IndexTTS-2`。

## 7. 扩展能力（非 Cursor / ChatBox 一键场景）

这些模型在 [/pricing](https://www.keyoapi.xyz/pricing) 可见，但**不是**标准「只填 Base URL」就能在聊天客户端里用完的；需要按路径用 HTTP / SDK 调用。

| 能力 | 路径 | 模型 |
|------|------|------|
| OCR / 文档理解（chat） | `POST /v1/chat/completions` | Unlimited-OCR |
| 文档解析（异步） | `POST /v1/async/documents/parse` → `GET /v1/task/{id}` | MinerU2.5-Pro |
| 抠图 | `POST /v1/images/mattings` | RMBG-2.0 |
| 超分 | `POST /v1/images/upscaling` | Real-ESRGAN、AnimeSharp |
| 文档展平 | `POST /v1/images/unwarping` | UVDoc |
| 目标检测 | `POST /v1/images/object-detection` | VajraV1、sam3 |
| 图像分割 | `POST /v1/images/segmentation` | VajraV1、sam3 |
| 人体关键点 | `POST /v1/images/pose-detection` | VajraV1 |
| 数字人（音视频→视频，异步） | `POST /v1/async/videos/audio-video-to-video` → `GET /v1/task/{id}` | Duix-Avatar |
| 说话视频（图→视频，异步） | `POST /v1/async/videos/image-to-video` → `GET /v1/task/{id}` | InfiniteTalk |
| 内容风控 | `POST /v1/moderations` | nonescape-v0、moark-text-moderation、Security-semantic-filtering、nsfw-classifier |


## 8. 在常见客户端里怎么填

**ChatBox / Cursor / 同类客户端（文本为主）**

- API 地址：`https://www.keyoapi.xyz/v1`  
- API Key：你的 `sk-...`  
- 模型：从 [/pricing](https://www.keyoapi.xyz/pricing) 选一个名字（必须完全一致）  
- 语音 / 抠图 / 数字人：请用本节 curl 或 OpenAI SDK / HTTP，不要指望聊天客户端自动支持全部接口

**OpenAI Python（对话）**

```python
from openai import OpenAI
client = OpenAI(
    base_url="https://www.keyoapi.xyz/v1",
    api_key="sk-你的密钥",
)
r = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "你好"}],
)
print(r.choices[0].message.content)
```

**查可用模型**

```bash
curl https://www.keyoapi.xyz/v1/models \
  -H "Authorization: Bearer sk-你的密钥"
```
