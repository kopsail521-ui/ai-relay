## 4. 在常见客户端里怎么填

**ChatBox / 同类客户端**

- API 地址：`https://www.keyoapi.xyz/v1`  
- API Key：你的 `sk-...`  
- 模型：从上表或 [/pricing](https://www.keyoapi.xyz/pricing) 选一个名字（必须完全一致）

**OpenAI Python**

```python
from openai import OpenAI
client = OpenAI(
    base_url="https://www.keyoapi.xyz/v1",
    api_key="sk-你的密钥",
)
r = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "你好"}],
)
print(r.choices[0].message.content)
```

**查可用模型**

```bash
curl https://www.keyoapi.xyz/v1/models \
  -H "Authorization: Bearer sk-你的密钥"
```
