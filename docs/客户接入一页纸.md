
### 4.2 视频生成（路径 B · generations）

> **客户可见文档：** https://www.keyoapi.xyz/brand/keyo-docs.html#video-api  
> 按模型字段表 + JSON/cURL（对齐常见中转站写法）。下文为同内容备份。

wan / Seedance / FLUX / MiniMax / Gemini Omni / grok-imagine **推荐**这条路径；`POST /v1/videos` 也会自动转发到这里。

`POST https://www.keyoapi.xyz/v1/videos/generations`  
轮询：`GET https://www.keyoapi.xyz/v1/tasks/{task_id}`（也可用 `GET /v1/videos/{id}`）

**媒体硬规则（所有模型）：**

- 请求体必须是 **JSON**（不要对生成口 multipart 传本地文件）
- 图 / 视频 / 音频地址只接受 **公网 `http://` / `https://`**
- **不要**传本机路径（如 `D:\...\a.png`）、**不要**传 `data:image/...;base64,...`
- 本机文件：先 `POST /v1/uploads`（别名 `/v1/files`）拿返回的 `url`，再写进 JSON；**没有** `POST /v1/assets` / `asset://`
- 轮询：`GET /v1/tasks/{task_id}`（复数 tasks，不是 TTS 的 `/v1/task/`）

| 模型 | 售价 | 计费 |
|------|------|------|
| gemini-omni-1.1-flash | **$0.1056/秒** | 按秒（无 `duration` 字段，时长由模型决定约 3–10s） |
| gemini-omni-1.1-flash-ext | 档位包（如 720P-8s **$0.42**）；参考视频按秒 | 档位或按秒 |
| seedance-2.5 | 480P **$0.1153/秒**；720P **$0.2592/秒**；1080P **$0.4619/秒** | 按秒（有参考用 input 档） |
| seedance-2.0 | 480P **$0.0792/秒**；720P **$0.1704/秒**；1080P **$0.4253/秒**；4K **$0.8664/秒** | 按秒 |
| flux-3-video | DRAFT **$0.0576**；HD **$0.1632**；FHD **$0.2784**/秒 | 按秒 |
| MiniMax-H3 | 480p **$0.02055/秒**；768p **$0.02877/秒**；1080p **$0.04110/秒** | 按秒 |
| wan3.0-video | 480P **$0.04115/秒**；720P **$0.08228/秒**；1080P **$0.16457/秒** | 按秒 |
| grok-imagine-video-1.5-preview | 480p **$0.08825/秒**；720p **$0.1545/秒** | **仅图生**；按秒 |

#### 4.2.1 通用：文生视频（示例）

```bash
curl https://www.keyoapi.xyz/v1/videos/generations \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"wan3.0-video\",
    \"prompt\": \"一只小猫在月光下的屋顶上奔跑\",
    \"resolution\": \"480P\",
    \"duration\": 5
  }"
```

各模型字段差异很大：**不要假设「多塞几张图」就等于图生/首尾帧/参考**。按下表选写法。

#### 4.2.2 `wan3.0-video`（模式由字段推断）

| 模式 | 怎么写 |
|------|--------|
| 文生 | 仅 `prompt` + `resolution` + `duration` |
| 首帧 | `image_urls`: **1** 张 https 图 |
| 首尾帧 | `image_urls`: **2** 张，或 `image_with_roles` 标 `first_frame` / `last_frame` |
| 参考生 | `generation_type":"reference"` + `image_urls` / `video_urls` / `audio_urls`（prompt 可用「图1」「视频1」指代） |
| 文件/网页参考 | `file_url` 或 `link_url` |

```json
{
  "model": "wan3.0-video",
  "prompt": "从微笑逐渐变为大笑",
  "image_with_roles": [
    {"url": "https://example.com/first.png", "role": "first_frame"},
    {"url": "https://example.com/last.jpg", "role": "last_frame"}
  ],
  "duration": 5,
  "resolution": "480P"
}
```

```json
{
  "model": "wan3.0-video",
  "prompt": "视频1抱着图1，在图3的椅子上弹奏",
  "generation_type": "reference",
  "image_urls": [
    "https://example.com/a.jpg",
    "https://example.com/b.png",
    "https://example.com/c.png"
  ],
  "video_urls": ["https://example.com/role.mp4"],
  "resolution": "480P",
  "duration": 5
}
```

**互斥：**「首尾帧族」与「参考族」不要混用；需要精确角色时用 `image_with_roles`。

#### 4.2.3 `seedance-2.0` / `seedance-2.5`

| 模式 | 怎么写 |
|------|--------|
| 文生 | `prompt` + `resolution` + `duration`（可加 `size`/`aspect_ratio`） |
| 图生（参考图） | `image_urls`: ["https://..."]（最多约 9 张） |
| 首尾帧 | `image_with_roles`: `first_frame` + `last_frame`（**不要**同时再塞 `video_urls`/`audio_urls`） |
| 参考视频 | `video_urls`: ["https://....mp4"] |
| 参考音频 | `audio_urls`: ["https://....mp3"] |
| 多模态参考 | `image_urls` + `video_urls` + `audio_urls`（与首尾帧互斥） |

```json
{
  "model": "seedance-2.0",
  "prompt": "Transition from day to night",
  "resolution": "480p",
  "duration": 5,
  "image_with_roles": [
    {"url": "https://example.com/day.jpg", "role": "first_frame"},
    {"url": "https://example.com/night.jpg", "role": "last_frame"}
  ]
}
```

```json
{
  "model": "seedance-2.0",
  "prompt": "Follow the motion of the reference clip",
  "resolution": "480p",
  "duration": 5,
  "video_urls": ["https://example.com/ref.mp4"]
}
```

#### 4.2.4 `flux-3-video`

| 模式 | 怎么写 |
|------|--------|
| 文生 | `prompt` + `duration`(5–20) + `resolution`：`hd`/`fhd`（也可用 `tier`：`DRAFT`/`HD`/`FHD`） |
| 图生/关键帧 | `image_urls`：1 张=首帧；2 张=首+尾；3–10=中间关键帧 |
| 视频续写 | `video_url` 或 `video_urls`（有视频时优先于图） |
| 草稿 | `draft: true`（仅 hd）；成片用 `draft_from_task_id` |

```json
{
  "model": "flux-3-video",
  "prompt": "Slow push-in as a flower opens",
  "image_urls": [
    "https://example.com/bud.jpg",
    "https://example.com/bloom.jpg"
  ],
  "duration": 5,
  "resolution": "hd"
}
```

#### 4.2.5 `MiniMax-H3`

**本模型字段与 Seedance/Wan 不同**（不要用 `image_urls` / `image_with_roles` / `first_frame_image`）。

| 字段 | 说明 |
|------|------|
| `model` | 固定 `MiniMax-H3` |
| `prompt` | 必填；建议写清时长、镜头、对白与负面提示（门槛较高） |
| `aspectRatio` | **必填语义**：`landscape`（横）/ `portrait`（竖）/ `square`（方）；也接受 `16:9`/`9:16`/`1:1` 别名 |
| `resolution` | `480p` / `768p` / `1080p` |
| `duration` | 1–15 秒；**1080p 最长 10 秒** |
| `images` | 可选，参考图数组，最多 9；元素为公网 **https URL** |
| `audios` | 可选，参考音频数组，最多 3；公网 **https URL** |
| `seed` | 可选，随机种子 |

兼容别名（会自动映射）：`image_urls`→`images`，`audio_urls`→`audios`，`aspect_ratio`→`aspectRatio`。

**文生：**

```json
{
  "model": "MiniMax-H3",
  "prompt": "一只红气球在蓝天缓缓上升，电影感，自然光",
  "aspectRatio": "landscape",
  "resolution": "480p",
  "duration": 5
}
```

**参考图 + 参考音频：**

```json
{
  "model": "MiniMax-H3",
  "prompt": "人物按参考音色说话，镜头缓慢推进",
  "aspectRatio": "portrait",
  "resolution": "768p",
  "duration": 8,
  "images": ["https://example.com/char.png"],
  "audios": ["https://example.com/voice.mp3"]
}
```

> 提交仍走 `POST /v1/videos/generations`，轮询 `GET /v1/tasks/{task_id}`（与其它视频模型同一套 Keyo 路径）。

#### 4.2.6 `gemini-omni-1.1-flash`

| 模式 | 怎么写 |
|------|--------|
| 文生 | `prompt` + `resolution`(`360p`/`720p`/`1080p`/`4k`) + `aspect_ratio`；**无 `duration`** |
| 多主体参考 | `image_urls` 多张 + prompt 说明关系 |
| 首尾帧 | `first_frame_image` + `last_frame_image`，或 `image_with_roles` |
| 视频编辑/延长 | `video_urls`（≤1 段，≤10s）或 `extend_from_task_id` |

```json
{
  "model": "gemini-omni-1.1-flash",
  "prompt": "smooth transition, camera slowly pushes in",
  "first_frame_image": "https://example.com/start.jpg",
  "last_frame_image": "https://example.com/end.jpg",
  "resolution": "720p"
}
```

`gemini-omni-1.1-flash-ext`：文生可用档位包；参考视频用 `video_urls`；也可 `image_urls` 做单图/多图参考。

#### 4.2.7 `grok-imagine-video-1.5-preview`（仅图生）

必填 `image: {"url":"https://..."}`（也接受 `image_url` / `image_urls[0]` 别名）。不要只传 prompt。

```json
{
  "model": "grok-imagine-video-1.5-preview",
  "prompt": "gentle camera push in",
  "image": {"url": "https://example.com/still.jpg"},
  "aspect_ratio": "16:9",
  "resolution": "480p",
  "duration": 5
}
```

## 6. 语音合成（TTS）

### 6.1 同步（立刻返回音频）

`POST https://www.keyoapi.xyz/v1/audio/speech`

```bash
curl https://www.keyoapi.xyz/v1/audio/speech \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d "{
    \"model\": \"GLM-TTS\",
    \"input\": \"你好，我是 KeyoAPI。\",
    \"voice\": \"alloy\"
  }" \
  --output speech.wav
```

适合：`GLM-TTS`、`Step-Audio-TTS-3B`、部分 `IndexTTS-2` 场景。

### 6.2 异步（先拿任务 ID，再轮询结果）

`POST https://www.keyoapi.xyz/v1/async/audio/speech`  
然后：`GET https://www.keyoapi.xyz/v1/task/{任务ID}`

```bash
# 创建任务
curl https://www.keyoapi.xyz/v1/async/audio/speech \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d "{\"model\":\"Qwen3-TTS\",\"input\":\"你好，异步语音合成。\"}"

# 用返回的 task id 查结果
curl https://www.keyoapi.xyz/v1/task/任务ID \
  -H "Authorization: Bearer sk-你的密钥"
```

适合：`Qwen3-TTS`、`CosyVoice3`，以及需要异步的 `IndexTTS-2`。

| 超分 | `POST /v1/images/upscaling` | Real-ESRGAN、AnimeSharp |

| 目标检测 | `POST /v1/images/object-detection` | VajraV1、sam3 |

| 人体关键点 | `POST /v1/images/pose-detection` | VajraV1 |
| 数字人（音视频→视频，异步） | `POST /v1/async/videos/audio-video-to-video` → `GET /v1/task/{id}` | ~~Duix-Avatar~~ **已下架**（上游要求双文件 multipart，且提交会超时） |

## 8. 在常见客户端里怎么填

**ChatBox / Cursor / 同类客户端（文本为主）**

- API 地址：`https://www.keyoapi.xyz/v1`  
- API Key：你的 `sk-...`  
- 模型：从 [/pricing](https://www.keyoapi.xyz/pricing) 选一个名字（必须完全一致）  
- 语音 / 抠图 / 数字人：请用本节 curl 或 OpenAI SDK / HTTP，不要指望聊天客户端自动支持全部接口

**OpenAI Python（对话）**

```python
from openai import OpenAI
client = OpenAI(
    base_url="https://www.keyoapi.xyz/v1",
    api_key="sk-你的密钥",
)
r = client.chat.completions.create(
    model="gpt-5.6-luna",
    messages=[{"role": "user", "content": "你好"}],
)
print(r.choices[0].message.content)
```

**查可用模型**

```bash
curl https://www.keyoapi.xyz/v1/models \
  -H "Authorization: Bearer sk-你的密钥"
```
