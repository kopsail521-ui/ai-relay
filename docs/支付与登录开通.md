# 线上充值开通清单（Stripe + 支付宝）

支付合规已在后台确认。要真正能自动到账，还差商户密钥（我无法替你申请）。

## A. Stripe（外卡 / 国际）

1. 打开 https://dashboard.stripe.com  
2. 创建 Product → 一个按金额充值用的 Price，记下 **Price ID**（`price_...`）  
3. Developers → API keys → 复制 **Secret key**（`sk_live_...` 或测试 `sk_test_...`）  
4. Developers → Webhooks → Add endpoint：  
   - URL：`https://www.keyoapi.xyz/api/stripe/webhook`（以 New API 后台提示为准）  
   - 事件：`checkout.session.completed`、`checkout.session.expired`  
   - 复制 **Signing secret**（`whsec_...`）  

填到后台：`系统设置 → 支付 / Billing → Stripe`  
或把下面三项发我（私聊/只写 .env，不要发群）：

```
STRIPE_API_SECRET=sk_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PRICE_ID=price_...
```

## B. 支付宝（国内，走易支付 Epay）

New API 不直连支付宝官方，常用 **易支付** 聚合：

1. 找一家易支付服务商，开通支付宝  
2. 拿到：`商户ID`、`商户密钥`、`支付网关地址`（如 `https://xxx.com`）  
3. 填到后台：`系统设置 → 支付 → Epay`  
   - PayAddress = 网关根地址（不要带回调路径）  
   - EpayId / EpayKey  

或发我：

```
EPAY_ADDRESS=https://你的易支付域名
EPAY_ID=商户ID
EPAY_KEY=商户密钥
```

## C. Google 登录（OIDC）

New API 没有单独「Google」开关，用 OIDC 接 Google：

1. Google Cloud Console → 创建 OAuth 客户端（Web）  
2. 授权重定向 URI 填：`https://www.keyoapi.xyz/oauth/oidc`  
3. 把 Client ID / Secret 发我或写进后台 OIDC，并打开 `oidc.enabled`

当前站点已预填 Google 的 endpoint，缺的是你的 Client ID/Secret。
