## 一、Stripe（外卡）逐步操作

### 1. 注册
1. 打开 https://dashboard.stripe.com/register  
2. 用邮箱注册并登录  
3. 左上角打开 **测试模式**（Test mode）开关（先测通再切正式）

### 2. 创建产品价格
1. 左侧 **产品目录（Product catalog）** → **添加产品**  
2. 名称：`KeyoAPI Credit`  
3. 定价模型选 **一次性付款 / One-off**  
4. 价格填：`1.00 USD`（表示按美元计价的充值单位，可与后台单价对应）  
5. 保存  
6. 点进该价格，复制 **价格 ID**，形如：`price_xxxxxxxxxxxxx`

### 3. 拿 API 密钥
1. 左侧 **开发者（Developers）** → **API 密钥**  
2. 在「保密密钥」点揭示/复制：  
   - 测试模式：`sk_test_...`  
   - 以后正式：`sk_live_...`

### 4. 配 Webhook
1. **开发者** → **Webhook** → **添加端点**  
2. 端点 URL 填（一字不差）：

```text
https://www.keyoapi.xyz/api/stripe/webhook
```

3. 要监听的事件，勾选：  
   - `checkout.session.completed`  
   - `checkout.session.expired`  
4. 添加端点  
5. 进入该端点详情 → **签名密钥** → 揭示，复制 `whsec_...`

### 5. 交给我写入站点
把下面三样放到本机文件（推荐）或私聊发我：

```text
STRIPE_API_SECRET=sk_test_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_PRICE_ID=price_...
```

我写入后，你用测试卡测一笔：  
卡号 `4242 4242 4242 4242`，任意未来有效期，任意 CVC。

## 二、支付宝（易支付）逐步操作

说明：New API **不能直接填支付宝开放平台**的 AppId/私钥，要走 **易支付（Epay）** 兼容接口。

### 1. 准备一个易支付商户
任选其一：
- 自行搜索「易支付 商户注册」（注意选能开支付宝、口碑相对正常的）  
- 或用你已有支付服务商提供的易支付接口  

注册审核通过后，后台一般能看到：

| 名称 | 说明 |
|------|------|
| 支付网关 / 接口地址 | 如 `https://pay.xxx.com` |
| 商户 ID（pid） | 数字或字符串 |
| 商户密钥（key） | 一串密钥 |
| 支付方式 | 需开启「支付宝」 |

### 2. 确认回调能到你的站
易支付一般会回调你的站点。New API 回调路径是：

```text
https://www.keyoapi.xyz/api/user/epay/notify
```

多数易支付**不用你在商户后台手填**这条（由请求参数带过去）；若后台有「异步通知域名」白名单，把 `www.keyoapi.xyz` 加上。

### 3. 交给我写入站点
```text
EPAY_ADDRESS=https://pay.你的易支付域名
EPAY_ID=商户ID
EPAY_KEY=商户密钥
```

注意：`EPAY_ADDRESS` 一般填**站点根**，不要带 `/submit.php` 等路径（以你服务商文档为准；不确定就截图发我）。

### 4. 测一笔
登录 KeyoAPI → 钱包/充值 → 选支付宝 → 小额 → 看额度是否到账。
