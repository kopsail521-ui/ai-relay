KeyoAPI Docs explains authentication, model selection, request formats and task queries for KeyoAPI.

Get started in five steps

  1. Create an account or sign in to your existing account.
  2. Create an API key in the console.
  3. Set the Base URL to https://www.keyoapi.xyz/v1 for OpenAI-compatible clients.
  4. Choose the exact model ID and its endpoint from the API handbook; use its documented fields.
  5. Save the returned request ID and any task ID. Query asynchronous tasks through the path documented for that model.
