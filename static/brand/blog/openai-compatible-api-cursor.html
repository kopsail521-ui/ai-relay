Use KeyoAPI in Cursor

Cursor speaks OpenAI-compatible chat. Swap base URL + key to route through KeyoAPI.

1. Get a key

  1. Create an account and top up Wallet if you will use metered models.
  2. Create an API key in the console.

2. Configure Cursor

In Cursor model / OpenAI-compatible settings (wording varies by Cursor version):

  • Base URL: https://www.keyoapi.xyz/v1
  • API Key: your Keyo key
  • Model: a live catalog ID, e.g. deepseek-v4.1-flash

Confirm IDs on /pricing-list or /pricing.

3. Smoke test

Send a short chat. If you see auth or balance errors, re-check the key and Wallet. Wrong model strings fail even with a valid key.

4. Free vs paid

For prototypes, start with a $0 ID from /free-models (fair-use). Switch the model string to a metered twin when you need higher priority.
