FAQ

KeyoAPI 常见问题 · Frequently asked questions

如何开始使用？

注册 / 登录 → 钱包充值 → 创建 API Key → 将 Base URL 设为 https://www.keyoapi.xyz/v1。公开价目见 /pricing。

如何充值？

登录后打开钱包 / Wallet，通过 Waffo 在线支付预付额度。额度即时到账用于 API 调用。

价格单位是什么？

控制台与模型广场以 USD 展示。文本模型多为按百万 tokens；图片等按次计费。以控制台实时扣费为准。

未登录能看价格吗？

可以。访问 /pricing（模型广场）。旧链接 /models 会自动跳转到公开价目页。

支持哪些客户端？

任何 OpenAI 兼容客户端：Cursor、ChatBox、OpenAI Python/Node SDK 等。接入说明见 文档。

常见报错？

模型名写错、API Key 无效、余额不足。请核对模型名与 /pricing 完全一致，并确认钱包有余额。

如何联系客服？

发邮件至 kopsail521@gmail.com，通常 3 个工作日内回复。服务状态：/status。
