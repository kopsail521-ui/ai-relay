FAQ

KeyoAPI frequently asked questions

How do I get started?

Sign up / sign in → top up Wallet → create an API Key → set Base URL to https://www.keyoapi.xyz/v1. Static public rates: the full pricing list. Interactive Model Square: the pricing page.

How do I top up?

Sign in and open Wallet. Choose an available payment method and confirm the amount and credited balance before paying. If credit is missing, check the payment record and contact support with the order ID.

What are the price units?

Prices are in USD. Units vary by model: tokens, requests, seconds, or characters. Some video models are per second; others are per request. Check the exact model, group, resolution and reference-input tier on the live pricing page before submitting.

Can I see prices without signing in?

Yes. Open the static list at the full pricing list (no sign-in). Interactive try/buy is on the pricing page (Model Square). Model guides live at the model guides page.

Are there free models?

Yes. Gift-credit models (IDs ending in :free) are billed at dedicated gift-credit rates; gift credits are used first (new users: $10; per invite: $3), with any shortfall charged to your recharge balance. Live list: the gift-credit models page.

Which clients are supported?

OpenAI-compatible clients can be configured with Base URL https://www.keyoapi.xyz/v1 and Chat Completions. Copy the complete model ID. Compatibility depends on the model, client version, streaming and tool requirements; a successful connection test does not verify all features. See setup instructions.

Common errors?

Wrong model name, invalid API key, or insufficient balance. Match the model ID exactly to the full pricing list and confirm Wallet has credits.

How do I contact support?

Email kopsail521@gmail.com — usually within 3 business days. Status: the status page.
