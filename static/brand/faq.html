FAQ

KeyoAPI frequently asked questions

How do I get started?

Sign up / sign in → top up Wallet → create an API Key → set Base URL to https://www.keyoapi.xyz/v1. Public prices: /pricing.

How do I top up?

After login, open Wallet and pay prepaid credits online via Waffo. Credits are available immediately for API calls.

What are the price units?

Console and Model Square show USD. Text models are usually per million tokens; images and similar tools are often per request. Live console billing is authoritative.

Can I see prices without signing in?

Yes. Open /pricing (Model Square). The old /models link redirects to the public pricing page.

Are there free models?

Yes. Model IDs with a -free suffix, e.g. deepseek-v4-flash-free, deepseek-v4-pro-free, glm-5.2-free, kimi-k3-free ($0; not the same model as the paid twin without the suffix). Full list: /pricing and Docs.

Which clients are supported?

Any OpenAI-compatible client: Cursor, ChatBox, OpenAI Python/Node SDK, and more. Setup notes: Docs.

Common errors?

Wrong model name, invalid API key, or insufficient balance. Match the model ID exactly to /pricing and confirm Wallet has credits.

How do I contact support?

Email kopsail521@gmail.com — usually within 3 business days. Status: /status.
