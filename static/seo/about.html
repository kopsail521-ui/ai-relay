One key for chat, image, video, speech, OCR & digital humans

KeyoAPI is a prepaid AI API gateway — one key for chat, speech, OCR and digital humans on a single balance. Chat, image and speech are OpenAI-compatible, while OCR, vision tools, async video/docs and digital-human models run on dedicated REST paths — same key, same prepaid balance. No five vendor dashboards, no five invoices.

Get started in five steps

  1. Create an account — new users receive $10 of gift credit for prototyping.
  2. Create an API key in the console.
  3. Point your OpenAI SDK at https://www.keyoapi.xyz/v1 with the model ID from this page, or call the dedicated REST path from the API handbook.
  4. Track spend in the console Wallet — $1 equals 500,000 quota units, and gift credit burns before recharged balance.
  5. Set a per-key spending cap before wiring production traffic.

A verified first call is the acceptance test for the setup: the response should carry the payload shape documented in the handbook, the Wallet ledger should show a deduction in quota units (500,000 units = $1), and repeated calls should deduct linearly at the listed rate. Any mismatch usually means the model ID or endpoint is wrong — check both against the pricing list before debugging client code.

What we do

We aggregate many model providers behind one prepaid account. For chat (and supported image/speech paths), keep the OpenAI SDK: set OPENAI_BASE_URL=https://www.keyoapi.xyz/v1 and swap model=. For OCR, matting, detection, async video and avatars, call the documented dedicated paths with the same key.

  • OpenAI-compatible paths: /v1/chat/completions, /v1/images/generations, /v1/audio/transcriptions, /v1/audio/speech.
  • Dedicated REST: OCR, CV tools, async TTS/video, digital humans — billed per page / request / second / characters.
  • One key, one balance: no per-vendor accounts or credits to manage.
  • Gift-credit models: callable with complimentary credits (new users: $10; per invite: $3). Billed at dedicated gift-credit rates with gift credits used first, fair-use limits — see the gift-credit models page.
