No free video tier — prototype on gift-credit IDs

The gift-credit IDs are chat and speech models only — there is no free video tier. They bill at normal rates from your one-time $10 new-user credit (fair-use limits) and are the right place to prove out base URL, auth and retry wiring. Then switch model= to agnes-video-2.5 on the same key; video bills per generated second — 720p starts at about $0.0205.

Rates and how to call

Agnes Video 2.5 is a text-to-video and image-to-video model. On KeyoAPI you POST /v1/videos/generations with model=agnes-video-2.5, a prompt, and the output resolution (720p / 1080p / 2k); clips run 1–12 seconds (default 5) and billing is per generated second from your prepaid wallet.

Optional inputs follow the same JSON body: aspectRatio (landscape / portrait / square, or 16:9 / 9:16 / 1:1), up to 9 reference images for image-to-video, up to 3 audio clips, and a seed. Keyo rates above are indicative sell prices from the live Keyo catalog — confirm the interactive card under the pricing page before volume.

For other video lanes on the same key see the seedance 2 5 api pricing page, the minimax h3 api pricing page and the flux 3 video api pricing page on the full pricing list; for post-generation cleanup see the subtitle erase pro api pricing page and the video enhance pro api pricing page.

curl https://www.keyoapi.xyz/v1/videos/generations \
  -H "Authorization: Bearer $KEYO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"agnes-video-2.5","prompt":"A drone shot over neon city rain, cinematic","duration":5,"resolution":"720p","aspectRatio":"landscape"}'
# Poll GET /v1/tasks/{id} with the same key: processing = still rendering, completed = ready url

FAQ

How long can an Agnes Video 2.5 clip be?

1 to 12 seconds, default 5. You are billed per generated second at the resolution you request.

Does Agnes Video 2.5 support image-to-video?

Yes — pass up to 9 https image URLs in the images field to animate a still, or leave it out for text-to-video.

How do I try Agnes Video 2.5 on Keyo?

Create a key at the sign-up page, then call POST /v1/videos/generations with model=agnes-video-2.5, or find it in the pricing page (Model Square).
