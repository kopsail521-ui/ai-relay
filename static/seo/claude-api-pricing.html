Both. Anthropic is the vendor brand; Claude is the model family. Keyo lists Claude-class model IDs (Sonnet, Opus, Fable) with indicative sell rates versus typical Anthropic public list bands — confirm live on /pricing/{id}.

How much does the Anthropic API cost on Keyo?

Indicative Keyo rows: Claude Sonnet ~$0.44/$2.21, Opus ~$1.10/$5.52, Fable tiers higher — all per 1M in/out. Confirm live on /model/claude-sonnet-5 (and sibling IDs). Anthropic’s own list bands change; treat official figures as planning context.

What should I do on Claude API 529 overloaded?

Treat 529 as capacity pressure: exponential backoff with jitter, circuit-break to a sibling Claude ID or cheaper GPT-class lane on the same Keyo key, and avoid stampedes. Walkthrough: /brand/blog/article/ncx234u2/.
