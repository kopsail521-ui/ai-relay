A worked task budget: 100K input + 10K output

Assume one task accumulates 100,000 billed input tokens and 10,000 billed output tokens across all its requests. This is an illustrative budget, not a measured average or a claim about typical Claude Code usage. If context is sent repeatedly, count each billed occurrence. These examples exclude cache-rate differences, group multipliers, additional charges and retries beyond that stated usage.

Cost = total input tokens / 1,000,000 × input rate + total output tokens / 1,000,000 × output rate.

API billing vs a monthly Claude plan

Compare your expected metered spend with the current first-party plan price, usage limits, included products and terms. A subscription may include access to Claude Code and other features; an API balance pays for API requests and does not establish the same entitlements. This page does not quote a subscription price because those terms can change.

Metered usage can suit occasional or uneven workloads, while a subscription can offer a predictable monthly outlay within its limits. Neither is always cheaper. Start with the token totals from completed tasks and account for caching, retries and human corrections before choosing. KeyoAPI balance rules and eligibility for gift credits are separate from first-party subscription billing.

Claude Code gateway compatibility: check before connecting

Claude Code requires a gateway that serves a supported API format; an OpenAI chat endpoint alone is not a Claude Code setup. KeyoAPI has a POST /v1/messages route, but this page does not claim a verified end-to-end Claude Code connection for the listed IDs.

One successful Messages response is only a first check. Validate the exact model IDs, streaming, tool-use and tool-result turns, and the requests made by your installed Claude Code version before production use. Model routing and any model alias configuration must match the gateway catalog. Do not assume the client’s default model name matches a KeyoAPI ID.

The example below demonstrates the catalog’s OpenAI-compatible chat endpoint. It is not a command to configure Claude Code. Check the API endpoint reference for the endpoint reference.

Make a metered chat request with a catalog ID

Use your API key from the console and the exact model value. This ordinary chat request lets you inspect response usage in your own application; it does not reproduce a multi-turn coding task.

curl https://www.keyoapi.xyz/v1/chat/completions \
  -H "Authorization: Bearer $KEYO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-sonnet-5-5","messages":[{"role":"user","content":"Review this migration plan: add a nullable column, backfill it, validate and enforce the constraint. Identify missing rollback steps."}],"max_tokens":400}'

Keep the task within a spending budget

Track usage for every request, stop after repeated failures, and cap the number of turns and the amount of context your application sends. Measure the cost per accepted result rather than the cost of one answer. If you use a supported client, check its own budget controls and usage reporting as well.

Calls to eligible gift-credit model IDs are billed by usage and consume gift credits under the account rules; they are not zero-cost inference. The bare paid IDs in this page’s examples do not establish gift-credit eligibility. Confirm your balance and model billing rules in the console.

FAQ

How many tokens does one Claude Code task use?

There is no fixed amount. Repository context, tool results, repeated turns, caching and retries affect billed usage. The 100K input plus 10K output on this page is a stated budget assumption; measure your own completed tasks.

Which listed model has the lowest token price?

Among the six checked IDs, claude-haiku-5-5 has the lowest default-group input and output rates. That does not establish the lowest cost per accepted coding task or Claude Code compatibility.

Can I point Claude Code directly at KeyoAPI now?

End-to-end client compatibility is not confirmed by this guide. POST /v1/messages exists, but the selected model route, streaming, tool cycle and client requests need validation. The chat curl shown here is not a Claude Code setup.

Is a prepaid API balance the same as a Claude subscription?

No. They have different billing, usage limits and product entitlements. Compare the current first-party plan terms with metered usage at the applicable API rates.
