No free video tier — prototype on gift-credit IDs

The gift-credit IDs are chat and speech models only — there is no free video tier. They bill at normal rates from your one-time $10 new-user credit (fair-use limits) and are the right place to prove out base URL, auth and retry wiring. Then switch model= to flux-3-video on the same key; video bills per generated second — the DRAFT tier starts at about $0.0576.

Rates and how to call

FLUX.3 Video is Black Forest Labs' video generation line. On KeyoAPI you call the OpenAI-compatible /v1/videos/generations endpoint with model=flux-3-video and pick a quality tier (DRAFT / HD / FHD) — or V2V tiers when you start from video. Billing is per second of generated output from your prepaid wallet.

Keyo rates above are indicative sell prices from the live Keyo catalog. Confirm the interactive card under the pricing page before volume, and treat Black Forest Labs official figures as planning context — list bands move.

DRAFT is the budget tier for quick iteration; HD and FHD cost more per second. V2V (video-to-video) tiers add a second input clip and bill at the higher end of the table.

curl https://www.keyoapi.xyz/v1/videos/generations \
  -H "Authorization: Bearer $KEYO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"flux-3-video","prompt":"A flower blooming, slow camera push-in","duration":5,"resolution":"hd"}'
# Poll GET /v1/tasks/{id} with the same key: processing = still rendering, completed = ready url

Get started in five steps

  1. Create an account — new users receive $10 of gift credit for prototyping.
  2. Create an API key in the console.
  3. Point your OpenAI SDK at https://www.keyoapi.xyz/v1 with the model ID from this page, or call the dedicated REST path from the API handbook.
  4. Track spend in the console Wallet — $1 equals 500,000 quota units, and gift credit burns before recharged balance.
  5. Set a per-key spending cap before wiring production traffic.

A verified first call is the acceptance test for the setup: the response should carry the payload shape documented in the handbook, the Wallet ledger should show a deduction in quota units (500,000 units = $1), and repeated calls should deduct linearly at the listed rate. Any mismatch usually means the model ID or endpoint is wrong — check both against the pricing list before debugging client code.

FAQ

What do the FLUX.3 Video tiers mean?

DRAFT is the fastest, lowest-cost tier for iterating. HD and FHD are higher-quality outputs at higher per-second rates. V2V tiers generate from a video input clip.

Is Keyo cheaper than official FLUX.3 Video pricing?

The Keyo rows are indicative sell rates from the live catalog. Black Forest Labs bands change, so treat this page as a planning snapshot and verify both sides before committing.

How do I try FLUX.3 Video on Keyo?

Create a key at the sign-up page and open the pricing page (Model Square) to find flux-3-video, or start with a gift-credit ID on the gift-credit models page.
