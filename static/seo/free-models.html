Gift-Credit AI Models — No Credit Card Required

KeyoAPI offers gift-credit models callable with your complimentary credits. Billed at dedicated gift-credit rates; gift credits are used first, with any shortfall charged to your recharge balance. New users get $10, and each successful invite earns $3. Register a key and set model to any ID in the table below.

The gift-credit catalog is a prototype lane of :free IDs on KeyoAPI, a prepaid AI API gateway: each bills at each model's dedicated gift-credit rate from gift credits first — new accounts start with $10, invites add $3 — and any shortfall falls through to the recharge balance on the same wallet.

Get started in five steps

  1. Create an account — new users receive $10 of gift credit for prototyping.
  2. Create an API key in the console.
  3. Point your OpenAI SDK at https://www.keyoapi.xyz/v1 with the model ID from this page, or call the dedicated REST path from the API handbook.
  4. Track spend in the console Wallet — $1 equals 500,000 quota units, and gift credit burns before recharged balance.
  5. Set a per-key spending cap before wiring production traffic.

A verified first call is the acceptance test for the setup: the response should carry the payload shape documented in the handbook, the Wallet ledger should show a deduction in quota units (500,000 units = $1), and repeated calls should deduct linearly at the listed rate. Any mismatch usually means the model ID or endpoint is wrong — check both against the pricing list before debugging client code.

Gift-credit rules (read before you ship)

  • Price: gift-credit IDs are billed at dedicated gift-credit rates (see table above and full pricing list). Gift credits are used first; any shortfall is charged to your recharge balance.
  • Complimentary credits: calls draw from your gift-credit balance (new users: $10; per successful invite: $3). When it runs out, top up to keep calling.
  • Fair use: gift-credit traffic has rate / concurrency limits. Limits can tighten under abuse. Do not treat gift-credit IDs as an unlimited production SLA.
  • Availability: some :free IDs may be added or removed from the catalog. Check Model Square before hard-coding.
  • Catch (honest): you get real capability with gift credits; you do not get paid-tier priority or guaranteed throughput.

FAQ

Can I use gift credits without a credit card?

Yes — gift-credit IDs are callable with your complimentary credits (new users: $10; per invite: $3) with no credit card required to start. Fair-use rate limits apply.

What's the catch?

Fair-use rate limiting and lower priority. Exact RPM can change; if you need predictable limits, use metered (paid) IDs.

Gift-credit vs paid?

Gift-credit IDs use your complimentary credits first (with fair-use limits). Paid IDs are token- or request-metered with higher priority — preferred for production.

Can I use it in production?

You can. For anything user-facing or latency-sensitive, we recommend metered IDs. Gift-credit models are ideal for prototypes, demos, CI smoke tests, and eval harnesses.

Why one hub page?

One page keeps every gift-credit ID and its limits in one place — bookmark it; we update it when the catalog changes.
