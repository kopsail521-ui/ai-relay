Rates and how to call

Engineers comparing Gemini API pricing usually already want Google-class models with clearer unit economics — or one prepaid balance across Gemini-class IDs plus DeepSeek, GLM, Whisper, OCR, and TTS. Official Google surfaces win on brand trust; KeyoAPI wins when you want that stack without five invoices.

Keyo rates above are indicative sell prices from the live Keyo catalog. Always confirm interactive pricing pages under /pricing/{modelId} before contracting volume. Catalog IDs can change as Google ships new stables — this page tracks what Keyo currently lists.

How to call: set OPENAI_BASE_URL=https://www.keyoapi.xyz/v1, use your Keyo API key, and pass the Gemini model string (for example gemini-3.8-flash) to POST /v1/chat/completions. Many Google-native features remain Google-console only; Keyo focuses on OpenAI-compatible chat access for overseas developer stacks.

When Gemini list prices spike your margin, keep Gemini for multimodal strengths and shift plain text volume to deepseek-v4.1-flash or gpt-6-luna on the same key. For pure free prototyping, start on the gift-credit models page, then promote to Gemini paid IDs when quality gates pass.

Gemini 4 API: Argon and Barium

The Gemini 4 family entry is Gemini 4 API on KeyoAPI. It links to the gemini-4-argon model page and the gemini-4-barium model page, both already listed in the model guides page. Use one of those exact model IDs for POST /v1/chat/completions. The checked default-group rates are $0.7353 input and $3.6765 output per million tokens for either ID. A bare gemini-4 is a family label, not a model listed in the checked catalog.

curl https://www.keyoapi.xyz/v1/chat/completions \
  -H "Authorization: Bearer $KEYO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-4-barium","messages":[{"role":"user","content":"Hello"}]}'

FAQ

Is Keyo cheaper than Google Gemini API pricing?

Often on the Flash/Omni rows we list — but Google’s public list, context tiers, and batch discounts change. Treat this table as a planning snapshot and verify both sides before you commit.

Do you offer a free Gemini model?

Yes — Atria-dawn-v2:free is a gift-credit catalog ID billed from your $10 welcome credit (fair-use). Other gift-credit IDs on the gift-credit models page sit on the same API key beside paid Gemini traffic.

Is Gemini 4 Argon available on KeyoAPI?

Yes — gemini-4-argon and its million-token sibling gemini-4-barium are live in the Keyo catalog at about $0.74 / $3.68 per 1M in/out. Confirm live rates on the gemini-4-argon model page and the gemini-4-barium model page.

KeyoAPI vs OpenRouter for gemini-3.8-flash and Omni request IDs?

Both put many model providers behind one API key with an OpenAI-compatible chat endpoint, so switching is a base_url + key change. KeyoAPI bills a prepaid wallet on one invoice and puts gift-credit prototyping IDs (billed from your one-time $10 new-user credit, fair-use) on the same key beside gemini-3.8-flash and Omni request IDs; OpenRouter is credit-based with per-model free tiers where offered. Compare the specific rates on this page against OpenRouter's live card before volume decisions.
