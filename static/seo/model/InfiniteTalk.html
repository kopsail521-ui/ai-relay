How to call it

  1. Create an account and top up the prepaid wallet — new accounts include $10 of gift credit.
  2. Create an API key in the console.
  3. Send the request: model=InfiniteTalk at POST /v1/async/videos/image-to-video.

Verify with one cheap call before production: the Wallet ledger should show the deduction in quota units (500,000 units = $1), repeated calls should deduct linearly at the listed rate, and a mismatch usually means the model ID or endpoint string is wrong — reconcile both against the pricing list before debugging client code.

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/async/videos/image-to-video

Model: model=InfiniteTalk

curl https://www.keyoapi.xyz/v1/async/videos/image-to-video \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F model=InfiniteTalk \
  -F "prompt=natural talking-head delivery" \
  -F cond_video=@./portrait.png \
  -F cond_audio=@./voice.wav
# then: GET /v1/task/{id}

Auth uses the same Bearer API key as chat. Full notes: Keyo docs.

FAQ

What inputs are required?

Upload a portrait image directly as cond_video, a driving audio file as cond_audio, and include prompt. Audio must be 15 seconds or shorter per job. Resolutions: 480P / 720P.

InfiniteTalk vs Duix-Avatar?

Both target digital humans; pick based on input modality and pricing unit (per request vs per second). Prototype both on KeyoAPI.
