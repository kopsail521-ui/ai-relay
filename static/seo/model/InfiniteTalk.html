Quick start

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/async/videos/image-to-video

Model: model=InfiniteTalk

curl https://www.keyoapi.xyz/v1/async/videos/image-to-video \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F model=InfiniteTalk \
  -F "prompt=natural talking-head delivery" \
  -F cond_video=@./portrait.png \
  -F cond_audio=@./voice.wav
# then: GET /v1/task/{id}

Auth uses the same Bearer API key as chat. Full notes: Keyo docs.

Input notes: use multipart fields cond_video and cond_audio. Audio must be 15 seconds or shorter per job. Resolutions: 480P / 720P. Poll GET /v1/task/{id}.
