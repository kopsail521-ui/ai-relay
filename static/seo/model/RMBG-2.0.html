Quick start

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/images/mattings

Model: model=RMBG-2.0

curl https://www.keyoapi.xyz/v1/images/mattings \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F model=RMBG-2.0 \
  -F image=@./photo.png
