Quick start

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/images/upscaling

Model: model=Real-ESRGAN

curl https://www.keyoapi.xyz/v1/images/upscaling \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F model=Real-ESRGAN \
  -F image=@./photo.png
