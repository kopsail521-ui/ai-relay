Overview

The current KeyoAPI endpoint accepts text or image state with typed questions, and returns choice / noul probabilities in a single forward pass without generating free-form text. Use it for request routing, ticket triage and classification.

Call POST /v1/decisions with model cloudflare/clef and a Bearer API key. Check Model Square for current availability and pricing.

Context and image limits

The model context is 65536 tokens, but the text state limit on the serving path is much smaller: only approximately the first 2000 text state tokens are read. The remaining text is truncated and not read. Put decision-critical facts first; do not assume a 65536-token state will be processed. Images count separately from this text limit.

Attach at most 4 images as base64 data URLs in PNG, JPEG or WebP format. Remote image URLs are not supported. Each image must be below 300KiB on the current endpoint.

Answers and usage

The request contains model, state and questions. Each named question declares a supported type (choice or noul) and its instructions. For a choice question, criteria declares the candidate labels. The response contains answers and usage with input_tokens, output_tokens: 0 and cost. These are structured decision probabilities, not a generated chat message. The current KeyoAPI endpoint does not accept score questions or JSON-object state; send state as supported text or image content.

Pricing

Input starts at $0.063 per 1M tokens and output is $0. Each request is billed for its actual usage, and the response’s usage.cost is the final charge in USD. Confirm current prices in Model Square before production traffic.

A decision model alongside a chat agent

Use Clef for a defined choice such as account, billing or technical support routing. Your application supplies the candidate labels and decides how to handle low confidence. The returned probabilities are not a guarantee of correctness; evaluate labeled examples and choose thresholds that match the cost of mistakes.

Clef is a Cloudflare decision model, separate from Claude-class chat. See Build an AI agent with the KeyoAPI chat API for the application execution loop, the Claude API pricing page for chat-model rates and Claude Code API Pricing: Budget the Whole Task for a stated coding-task token budget.

Read the final charge from usage.cost

The response usage.cost is the final KeyoAPI charge in USD — use it as returned; no further conversion is needed. Wallet deductions follow the service’s quota precision; output_tokens is 0 for this decision protocol.

At the starting input rate, 1,000 input tokens would estimate $0.000063. This is arithmetic at the starting rate, not a guaranteed request price or a live inference measurement. Use the returned usage.cost and your console usage records for the actual charge.

FAQ

Does Clef generate chat or free-form text?

No. A single forward pass returns typed choice / noul probabilities in answers. The current endpoint does not accept score questions. Use POST /v1/decisions.

Can Clef read a 65536-token text state?

Do not rely on it. 65536 is the model context length; the serving text state is truncated after approximately the first 2000 tokens and the remainder is not read. Images count separately.

Can I send remote image URLs?

No. Use up to 4 base64 data URL images in PNG, JPEG or WebP format, each below 300KiB.

Is $0.063/M the fixed input price?

No. It is the starting rate. Output is $0, and usage.cost returns the final request charge. Use the returned usage.cost as the actual charge; no further conversion is needed.

Is Clef a Claude model?

No. cloudflare/clef is a Cloudflare decision model. Use /v1/decisions for typed probabilities; use a chat model for free-form explanations or generation.
