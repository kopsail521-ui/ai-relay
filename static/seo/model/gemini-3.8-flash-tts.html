Overview

gemini-3.8-flash-tts is Gemini Flash text-to-speech on KeyoAPI. Indicative rates about $0.44 / $8.82 per 1M in/out — confirm live on /pricing/gemini-3.8-flash-tts. Call POST /v1/chat/completions at https://www.keyoapi.xyz/v1 with modalities ["text","audio"] and receive audio inline in the same response (sync). Use IndexTTS-2 or CosyVoice3 when you already run async TTS jobs.

Quick start

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/chat/completions

Model: model=gemini-3.8-flash-tts

curl https://www.keyoapi.xyz/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemini-3.8-flash-tts","modalities":["text","audio"],"audio":{"voice":"Kore","format":"wav"},"messages":[{"role":"user","content":"Hello from Gemini 3.8 Flash TTS."}]}'

Auth uses the same Bearer API key as chat. Full notes: Keyo docs.

FAQ

Sync or async?

Sync: audio returns inline in the chat completion response (modalities ["text","audio"]). Async TTS on Keyo remains Qwen3-TTS / CosyVoice3.
