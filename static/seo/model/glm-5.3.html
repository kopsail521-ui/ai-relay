How to call it

  1. Create an account and top up the prepaid wallet — new accounts include $10 of gift credit.
  2. Create an API key in the console.
  3. Send the request: model=glm-5.3 at POST /v1/chat/completions.

Verify with one cheap call before production: the Wallet ledger should show the deduction in quota units (500,000 units = $1), repeated calls should deduct linearly at the listed rate, and a mismatch usually means the model ID or endpoint string is wrong — reconcile both against the pricing list before debugging client code.
