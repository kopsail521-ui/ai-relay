Overview

Nano Banana 2 is Google's image generation model, served on KeyoAPI through the OpenAI-compatible /v1/images/generations endpoint. If you already call chat, Whisper, or OCR with a KeyoAPI key, image generation is one more model string — no Google Cloud project, no second credential.

Pricing is simple: $0.0205 per generated image. It sits between the nano-banana-2.1 model page ($0.0123, the newer release) and the nano-banana-pro model page ($0.0274, the top tier) — all three on the same key, so A/B testing a prompt across tiers is a model-string change.

Call it with POST /v1/images/generations, model=nano-banana-2, and a prompt. Use aspectRatio="1:1" and imageSize="1K" to request a square 1K image. Responses come back in the OpenAI images shape, so existing clients and SDKs work after pointing base_url at https://www.keyoapi.xyz/v1.

When to pick this lane: keep nano-banana-2 where your stack pins the base generation, prefer the nano-banana-2.1 model page for newer-release quality at a lower per-image price, and escalate to the nano-banana-pro model page when fidelity dominates. Use aspectRatio (for example 1:1) and imageSize (1K, 2K or 4K); do not send GPT-style pixel sizes. Keep the returned task_id: HTTP 202 means the same task is still running. Query GET /v1/images/tasks/{task_id} with the same API key until HTTP 200, status=succeeded and data[].url is nonempty. A new generation needs a new idempotency key. Recover the same operation with its original key and identical parameters; do not change the key just because the result is slow. Temporary GET errors should retry the same saved task, not create another image. See the API endpoint reference for the complete image contract.

Keep the task receipt and request parameters with your project before waiting for an image. A temporary query failure should resume the same task ID. A new prompt is a new operation and needs a new idempotency key; recovery of the same operation retains its existing key and parameters. Download a successful image while its result URL remains available, and record terminal errors instead of starting a replacement automatically.

How to call it

  1. Create an account and top up the prepaid wallet — new accounts include $10 of gift credit.
  2. Create an API key in the console.
  3. Send the request: model=nano-banana-2 · prompt required · aspectRatio=1:1 · imageSize=1K at POST /v1/images/generations.

Verify with one cheap call before production: the Wallet ledger should show the deduction in quota units (500,000 units = $1), repeated calls should deduct linearly at the listed rate, and a mismatch usually means the model ID or endpoint string is wrong — reconcile both against the pricing list before debugging client code.

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/images/generations

Model: model=nano-banana-2 · prompt required · aspectRatio=1:1 · imageSize=1K

curl https://www.keyoapi.xyz/v1/images/generations \
  -H "Authorization: Bearer $KEYO_API_KEY" \
  -H "Idempotency-Key: replace-with-a-unique-key-for-this-image" \
  -H "Content-Type: application/json" \
  -d '{"model":"nano-banana-2","prompt":"a mug of coffee on a desk, studio light","aspectRatio":"1:1","imageSize":"1K","replyType":"async"}'
# Save task_id; query GET /v1/images/tasks/{task_id} with the same key.

FAQ

How do I call the Nano Banana 2 API?

POST /v1/images/generations with the exact model ID, prompt, aspectRatio, imageSize and replyType:"async". Read HTTP 202 and task_id, then poll GET /v1/images/tasks/{task_id} until HTTP 200, status:"succeeded" and non-empty data[].url. SDK custom fields may require extra_body. See the image contract in the integration handbook before submitting.

Nano Banana 2 vs 2.1 vs Pro — which one?

nano-banana-2 is the base lane at $0.0205 per image; nano-banana-2.1 is the newer release at $0.0123 per image; nano-banana-pro is the top tier at $0.0274. All three run on the same key — see the nano-banana-2.1 model page, the nano-banana-pro model page and the full pricing list.
