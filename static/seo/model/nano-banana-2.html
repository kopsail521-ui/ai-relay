Overview

Nano Banana 2 is Google's image generation model, served on KeyoAPI through the OpenAI-compatible /v1/images/generations endpoint. If you already call chat, Whisper, or OCR with a KeyoAPI key, image generation is one more model string — no Google Cloud project, no second credential.

Pricing is simple: $0.0205 per generated image. It sits between nano-banana-2.1 ($0.0123, the newer release) and nano-banana-pro ($0.0274, the top tier) — all three on the same key, so A/B testing a prompt across tiers is a model-string change.

Call it with POST /v1/images/generations, model=nano-banana-2, and a prompt. size is optional (1024x1024 by default). Responses come back in the OpenAI images shape, so existing clients and SDKs work after pointing base_url at https://www.keyoapi.xyz/v1.

When to pick this lane: keep nano-banana-2 where your stack pins the base generation, prefer 2.1 for newer-release quality at a lower per-image price, and escalate to pro when fidelity dominates. Confirm live rates on /pricing-list before volume work.

Quick start

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/images/generations

Model: model=nano-banana-2 · prompt required · size optional (e.g. 1024x1024)

curl https://www.keyoapi.xyz/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"nano-banana-2","prompt":"a mug of coffee on a desk, studio light","size":"1024x1024"}'

Auth uses the same Bearer API key as chat. Full notes: Keyo docs.

FAQ

How do I call the Nano Banana 2 API?

Use your KeyoAPI Bearer key and POST to /v1/images/generations with model=nano-banana-2 and a prompt. The endpoint is OpenAI-compatible, so existing image clients work with a base URL change.

Nano Banana 2 vs 2.1 vs Pro — which one?

nano-banana-2 is the base lane at $0.0205 per image; nano-banana-2.1 is the newer release at $0.0123 per image; nano-banana-pro is the top tier at $0.0274. All three run on the same key — see /model/nano-banana-2.1 and /pricing-list.
