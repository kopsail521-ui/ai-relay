Overview

Nano Banana Pro is the top tier of Google's Nano Banana image family, served on KeyoAPI through the OpenAI-compatible /v1/images/generations endpoint. If you already call chat, Whisper, or OCR with a KeyoAPI key, image generation is one more model string — no Google Cloud project, no second credential.

Pricing is per generated image: $0.0274 on pro, against nano-banana-2 at $0.0205 (base lane) and nano-banana-2.1 at $0.0123 (newer release). Pro earns its premium when fidelity dominates — higher resolution output and finer editing control for commercial visuals, detailed image work and art direction. All three tiers run on the same key, so escalating a prompt from 2.1 to pro is a model-string change.

Call it with POST /v1/images/generations, model=nano-banana-pro, and a prompt. size is optional (1024x1024 by default). Responses come back in the OpenAI images shape synchronously — no task polling — so existing clients and SDKs work after pointing base_url at https://www.keyoapi.xyz/v1. Quick start

Base URL: https://www.keyoapi.xyz/v1

Endpoint: POST /v1/images/generations

Model: model=nano-banana-pro · prompt required · size optional (e.g. 1024x1024)

curl https://www.keyoapi.xyz/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"nano-banana-pro","prompt":"a mug of coffee on a desk, studio light","size":"1024x1024"}'

Auth uses the same Bearer API key as chat. Full notes: Keyo docs.

FAQ

How do I call the Nano Banana Pro API?

Use your KeyoAPI Bearer key and POST to /v1/images/generations with model=nano-banana-pro and a prompt. The endpoint is OpenAI-compatible, so existing image clients work with a base URL change.

Nano Banana Pro vs 2 vs 2.1 — which one?

nano-banana-pro is the top tier at $0.0274 per image with higher resolution and finer editing control; nano-banana-2 is the base lane at $0.0205; nano-banana-2.1 is the newer release at $0.0123. All three run on the same key — see the nano-banana-2.1 model page, the nano-banana-2 model page and the full pricing list.
