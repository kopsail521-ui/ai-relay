Where it fits

Speech models on KeyoAPI split into transcription (audio in, text out via multipart upload) and synthesis (text in, audio out, some via async task polling). Both directions bill on the same prepaid wallet as chat, so voice features can ride an existing balance without a second vendor account. For pipelines, transcription feeds agents and logs; synthesis closes the loop for voice replies.

Limits and good-fit use

Audio format and duration limits follow the endpoint contract: sync speech returns audio bytes directly, while async speech submits a task and returns a pollable id. Always verify live rates on the pricing list — speech models meter per request, per second or per 10k characters depending on the model.

Request contract

Speech requests split by direction. Transcription uploads audio as multipart form data with the model field, returning JSON text; synthesis posts JSON (or multipart for some clones) and returns audio bytes synchronously, or a task id for async lanes that you poll on the task endpoint until the render completes. Both directions authenticate with the same Bearer key as chat, and both deduct from the same prepaid wallet at the per-request or per-character rate listed above.

How to call it

  1. Create an account and top up the prepaid wallet — new accounts include $10 of gift credit.
  2. Create an API key in the console.
  3. Send the request: model=whisper-large-v3 at POST /v1/audio/transcriptions.

Verify with one cheap call before production: the Wallet ledger should show the deduction in quota units (500,000 units = $1), repeated calls should deduct linearly at the listed rate, and a mismatch usually means the model ID or endpoint string is wrong — reconcile both against the pricing list before debugging client code.
