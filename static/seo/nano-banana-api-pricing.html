Rates and how to call

Nano Banana is Google's image generation family. On KeyoAPI all three tiers run on the same OpenAI-compatible endpoint: POST /v1/images/generations with model=nano-banana-2.1 (newer release, $0.0123 per image), model=nano-banana-2 (base lane, $0.0205) or model=nano-banana-pro (top tier with higher resolution and finer editing control, $0.0274). Use each model’s documented aspect-ratio and imageSize limits.

Billing is per generated image. A request can return a result immediately or HTTP 202 with a continuing task; save task_id and query GET /v1/images/tasks/{task_id} with the same API key. Keyo rates above are indicative sell prices from the live Keyo catalog; confirm the interactive card under the pricing page before volume, and treat official Google figures as planning context — list bands move.

Per-tier walkthroughs live on the model guides: the nano-banana-2.1 model page, the nano-banana-2 model page and the nano-banana-pro model page. For other image lanes on the same key (gpt-image and friends) see the full pricing list.

Use aspectRatio (for example 1:1) and imageSize (1K, 2K or 4K); do not send GPT-style pixel sizes. Keep the returned task_id: HTTP 202 means the same task is still running. Query GET /v1/images/tasks/{task_id} with the same API key until HTTP 200, status=succeeded and data[].url is nonempty. See the API endpoint reference for reference images, idempotency and error recovery.

curl https://www.keyoapi.xyz/v1/images/generations \
  -H "Authorization: Bearer $KEYO_API_KEY" \
  -H "Idempotency-Key: replace-with-a-unique-key-for-this-image" \
  -H "Content-Type: application/json" \
  -d '{"model":"nano-banana-2.1","prompt":"a mug of coffee on a desk, studio light","aspectRatio":"1:1","imageSize":"1K","replyType":"async"}'
# Save task_id; query GET /v1/images/tasks/{task_id} with the same key.

Get started in five steps

  1. Create an account — new users receive $10 of gift credit for prototyping.
  2. Create an API key in the console.
  3. Point your OpenAI SDK at https://www.keyoapi.xyz/v1 with the model ID from this page, or call the dedicated REST path from the API handbook.
  4. Track spend in the console Wallet — $1 equals 500,000 quota units, and gift credit burns before recharged balance.
  5. Set a per-key spending cap before wiring production traffic.

A verified first call is the acceptance test for the setup: the response should carry the payload shape documented in the handbook, the Wallet ledger should show a deduction in quota units (500,000 units = $1), and repeated calls should deduct linearly at the listed rate. Any mismatch usually means the model ID or endpoint is wrong — check both against the pricing list before debugging client code.

FAQ

Which Nano Banana tier should I use?

Start with nano-banana-2.1 — the newer release at the lowest per-image rate ($0.0123). Keep nano-banana-2 where your stack pins the base lane ($0.0205), and escalate to nano-banana-pro ($0.0274) when you need higher resolution and finer editing control for commercial work.

How is Nano Banana billed on KeyoAPI?

Per generated image, at the tier's rate. The images endpoint may return HTTP 202 while processing. Save task_id and poll GET /v1/images/tasks/{task_id}; do not resubmit a new generation.

How do I try Nano Banana on Keyo?

Create a key at the sign-up page and open the pricing page (Model Square) to find the nano-banana tiers, or start with a gift-credit ID on the gift-credit models page to wire your client first.
