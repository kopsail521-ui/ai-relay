Rates and how to call

Seedance 2.0 is ByteDance's mature video generation family, fully supported on KeyoAPI across three unified model tiers: standard (seedance-2.0), accelerated (seedance-2.0-fast), and budget (seedance-2.0-mini). Resolution is passed as a request parameter (480p, 720p default, or 1080p) rather than suffixed in the model name: POST /v1/videos/generations with model=seedance-2.0-mini starts at about $0.0321 per second for 480p and $0.0499 for 720p.

Clips run 4 to 15 seconds (default 5); duration or seconds is the main extra field you usually need. Image inputs follow Seedance conventions: first_frame_image for a first frame, image_urls for reference generation, image_with_roles for first+last frame. Keyo rates above are indicative sell prices from the live Keyo catalog — confirm the interactive card under the pricing page before volume.

For the current-generation flagship see the seedance 2 5 api pricing page; for other video lanes on the same key see the minimax h3 api pricing page, the flux 3 video api pricing page, the wan3 video api pricing page and the agnes video 2 5 api pricing page, all listed on the full pricing list.

FAQ

Is there a free Seedance 2.0 API?

No free Seedance ID exists on Keyo — the gift-credit IDs are chat and speech models only. Use them (billed from your one-time $10 new-user credit, fair-use limits) to prove out your wiring, then switch model= to a Seedance model. The lowest-cost tier is seedance-2.0-mini at about $0.0321 per second for 480p and $0.0499 for 720p.

What is the difference between standard, fast and mini Seedance 2.0 tiers?

Same resolution family, different cost/latency/quality trade-offs: standard (seedance-2.0) is the full-quality tier, fast (seedance-2.0-fast) prioritizes turnaround at lower per-second cost, and mini (seedance-2.0-mini) is the high-efficiency budget tier. All three accept resolution parameters (480p / 720p / 1080p) and bill per generated second.

How do I specify resolution in Seedance 2.0 requests?

Pass resolution: "720p" (or "480p" / "1080p") in your POST /v1/videos/generations JSON payload. If omitted, it defaults to 720p. Legacy model IDs with resolution suffixes (such as seedance-2.0-1080p) also remain supported for backwards compatibility.

How long can a Seedance 2.0 clip be?

4 to 15 seconds, default 5 — the same window as Seedance 2.5. Requests outside that range are rejected rather than clamped.
