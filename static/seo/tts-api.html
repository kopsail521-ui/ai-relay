Rates and endpoints

TTS models do not share one interchangeable request body. GLM-TTS, Step-Audio-TTS-3B, IndexTTS-2 and Eleven use POST /v1/audio/speech. Qwen3-TTS, CosyVoice3 and Spark-TTS-0.5B use POST /v1/async/audio/speech, then singular GET /v1/task/{id}.

Qwen3-TTS requires an inputs array of objects containing prompt and language (Chinese or English); speaker and instruction are optional model-specific controls. CosyVoice3 requires string inputs plus prompt_wav_url and its exact prompt_text, with a reference ≤30 seconds, ≥16 kHz, WAV/MP3. IndexTTS-2 requires prompt_audio_url and a chosen text/audio emotion branch. See the API endpoint reference for complete examples.

GLM reference examples use prompt_audio_url plus its matching prompt_text; Step references are optional WAV. There is no confirmed interchangeable alloy/echo voice list for these models. Spark basic synthesis explicitly supplies gender, with pitch and speed from one to five. Eleven uses model-specific built-in names such as george; do not copy another service’s voice ID. Request success does not guarantee language, gender, emotion or voice quality.

Gemini 3.8 Flash TTS uses only POST /v1beta/models/gemini-3.8-flash-tts:generateContent, not /v1/audio/speech. Its JSON response contains inlineData.mimeType and base64 data; decode audio according to MIME and wrap raw PCM when needed. See the API endpoint reference for the decoder. The preview TTS model and keyo-tts remain pending; laya is not TTS and InfiniteTalk needs existing audio.

Replace reference URL placeholders with real downloadable files and exact transcripts before submitting. Save task IDs; retry temporary task_query_unavailable GETs according to Retry-After without creating replacement jobs. Check current rates and account groups on the pricing page.

Get started in five steps

  1. Create an account — new users receive $10 of gift credit for prototyping.
  2. Create an API key in the console.
  3. Point your OpenAI SDK at https://www.keyoapi.xyz/v1 with the model ID from this page, or call the dedicated REST path from the API handbook.
  4. Track spend in the console Wallet — $1 equals 500,000 quota units, and gift credit burns before recharged balance.
  5. Set a per-key spending cap before wiring production traffic.

A verified first call is the acceptance test for the setup: the response should carry the payload shape documented in the handbook, the Wallet ledger should show a deduction in quota units (500,000 units = $1), and repeated calls should deduct linearly at the listed rate. Any mismatch usually means the model ID or endpoint is wrong — check both against the pricing list before debugging client code.

FAQ

Which TTS model should I start with?

Use the complete model-specific request in the API endpoint reference: Qwen requires a prompt/language array; Cosy and Index need reference audio. Choose sync or async based on your application, and check live rates on the pricing page.

Is there a free TTS model?

Spark-TTS-0.5B:free is listed as a gift-credit TTS ID. The :free suffix does not promise every model has a zero rate; check the current per-model rate and wallet fallback rules. See the gift-credit models page and the CosyVoice3 model page.

Can I pair TTS with avatars?

Yes — generate audio, then drive Duix-Avatar or InfiniteTalk on the same key. Guides: the Duix-Avatar model page, hub the AI avatar video generator page.
